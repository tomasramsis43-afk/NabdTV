# معمارية jolo

تطبيق IPTV أصلي (Native) لأندرويد TV والموبايل، مبني على Kotlin + Jetpack Compose + Media3.
القرار التقني: الإبقاء على نفس المنصة الحالية في الريبو (بدل الانتقال إلى React/Flutter)، لأن Media3/ExoPlayer يعطي أفضل تسريع عتادي (MediaCodec) وأسرع تبديل قنوات على أجهزة التلفاز، والتطبيق كله Client-side بدون سيرفر وسيط.

## الطبقات

```
UI (Compose)         Screens: Home · Live · Movies · Series · Guide · Recordings · Settings · Player · MultiView
   │
ViewModel            AppViewModel (حالة الواجهة فقط، بدون منطق شبكة)
   │
Domain               Classifier (تصنيف تلقائي) · Recommender (توصيات) · ParentalControl · HealthChecker · EpgMatcher
   │
Data                 Repo (Xtream / M3U) · EpgParser · JsonStore (تخزين محلي) · MetadataRepo (TMDB اختياري)
   │
Background           WorkManager: RefreshWorker (قائمة + EPG + فحص المفضلة) · RecordingService (تسجيل)
```

## الميزات وكيف تُنفَّذ

| الميزة | التنفيذ |
|---|---|
| Auto-EPG | تحميل XMLTV، ربط بالـ tvg-id أولاً ثم مطابقة اسم القناة المطبَّع (Fuzzy) مع display-name، تحديث كل 6 ساعات في الخلفية |
| Catchup | قنوات Xtream ذات `tv_archive` عبر رابط timeshift، وقوائم M3U عبر `catchup-source`؛ تُشغَّل من شاشة الدليل |
| التسجيل المجدول | جدولة من الدليل (برنامج واحد أو كل حلقات عنوان مفضّل)، خدمة Foreground تنسخ البث إلى ملف محلي |
| Health Check | فحص سلبي (تعلّم من أخطاء التشغيل الفعلية) + فحص نشط يدوي/مجدول للمفضلة فقط وبتوازي منخفض لتفادي استهلاك حد الاتصالات المتزامنة في حسابات Xtream |
| بدائل الروابط | تجميع القنوات بالاسم المطبَّع (HD/FHD/SD) وتحويل تلقائي لأول بديل سليم عند الفشل |
| التوصيات | محرك محلي على الجهاز: متجه اهتمامات من سجل المشاهدة (تصنيف + وقت اليوم + حداثة) وتشابه كوسيني مع كل عنصر |
| التصنيف والتحكم الأبوي | قواعد كلمات مفتاحية (عربي/إنجليزي) → أنواع؛ ملفات: أطفال / مراهق / بالغ؛ PIN مشفّر (SHA-256 + salt)؛ المحتوى المقفل مخفي حتى إدخال الرمز |
| المشغّل | HLS / DASH / MP4 / TS، فك ترميز عتادي مع fallback برمجي، Buffers صغيرة للتبديل السريع، اختيار الصوت والترجمة وتخصيص شكل الترجمة، تفضيل لغة (عربي) تلقائياً |
| Multi-Screen | شبكة 2 أو 4 مشغّلات، واحد فقط بصوت والباقي مكتوم |
| Metadata | بوسترات وخلفيات وملخص وتقييم من Xtream (`get_vod_info` / `get_series_info`)، وTMDB كبديل عند توفر مفتاح |

## التصميم

داكن بدرجات Netflix/Apple TV، بطاقات زجاجية (Glassmorphism) بشفافية وتدرّج وحدود ناعمة، تكبير سلس للعنصر المركَّز بالريموت، صف Hero في الرئيسية وصفوف أفقية (متابعة المشاهدة، مقترح لك، المفضلة، حسب التصنيف). تخطيط متجاوب: ريموت (D-pad) على التلفاز ولمس على الموبايل.

## قيود صريحة

- الترجمة التلقائية = اختيار تلقائي للغة المفضلة من المسارات المتوفرة، لا ترجمة آلية للصوت.
- التوصيات خوارزمية محلية وليست نموذج سحابي، وبياناتها لا تغادر الجهاز.
- لا يمكن بناء الـ APK محلياً في بيئة العمل هنا؛ التحقق يتم عبر GitHub Actions الموجود.

## أفكار مستلهمة من StreamVault-IPTV

مصدر الإلهام فقط (ترخيصه غير تجاري ولا يُنسخ منه كود)؛ كل التنفيذ هنا مكتوب مستقلاً.

- إدخال رقم القناة بالريموت (أرقام مباشرة) وترقيم القنوات.
- المشاهَد مؤخراً، مجموعات مخصصة، تثبيت/إخفاء/قفل تصنيف بالضغط المطوّل.
- بحث شامل عبر المباشر والأفلام والمسلسلات.
- دليل EPG يظهر فوق البث (Overlay) + تعديل يدوي لمطابقة القناة بالدليل.
- استكمال المشاهدة من آخر موضع، والحلقة التالية تلقائياً.
- نسبة العرض وسرعة التشغيل داخل المشغّل.
- تذكير بالبرامج (إشعار بدون تسجيل).
- فلترة كلمات مزعجة من أسماء التصنيفات.
- شاشة البداية قابلة للتخصيص.
- مصادر متعددة (Providers) مع تبديل سريع.

مؤجَّل بقرار: Timeshift محلي 30 دقيقة، تنزيل VOD للأوفلاين، Cast، Watch Next، QR pairing.
